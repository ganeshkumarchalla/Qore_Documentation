Getting started with QORE

QORE is a local-first quantum workbench for authoring circuits, running controlled Aer simulations, understanding state output, proving transformations, and preserving experiment evidence.

Run QORE

.\.venv\Scripts\python.exe -m uvicorn qore.main:app --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000. Create a project in Explorer, write a supported Qiskit circuit, and run it from Quantum Lab.

First Bell-state experiment

from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)
qc.h(0)
qc.cx(0, 1)
qc.measure([0, 1], [0, 1])

With an ideal simulator this produces correlated 00 and 11 results.
