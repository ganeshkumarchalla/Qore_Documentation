Getting started with QORE

QORE is a local-first quantum development environment for authoring, simulating, validating, and preserving experiments. It combines an editable workspace with a constrained Qiskit circuit compiler, bounded Aer execution, visual analysis, transformation validation, and an experiment ledger.

Before you begin

Install Python 3.11–3.13 and the project dependencies. Local Qiskit Aer simulation works without cloud credentials. QORE includes Qiskit, Aer, IBM Runtime client support, and selected published add-ons. IBM hardware services require separately authorized backend-only credentials.

Start the application

.\.venv\Scripts\python.exe -m uvicorn qore.main:app --host 127.0.0.1 --port 8000

Open http://127.0.0.1:8000. Explorer manages projects and files; the editor holds your circuit; Quantum Lab runs it; Forge validates transformations; Ledger preserves evidence; Terminal reports diagnostics.

First experiment: a Bell pair

from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)
qc.h(0)
qc.cx(0, 1)
qc.measure([0, 1], [0, 1])

H creates superposition. CX correlates the second qubit with the first. Measurement produces classical bitstrings. Under ideal simulation, expected outcomes are 00 and 11. Finite shots affect the count balance, not the ideal set of outcomes.

Run and interpret

Choose shots and a seed, then execute from Quantum Lab. Start with the distribution: it compares sampled counts with ideal statevector probability. Check metadata for backend, seed, shots, noise model, timing, timestamp, and total variation distance. State World explains register-level outcomes; Bloch views show each qubit’s reduced state.

Reproducibility

Keep circuit source, seed, shot count, noise settings, backend, and version information together. Ledger preserves this record, supports historical comparison, and exports JSON evidence. A result without its source and configuration cannot be independently reproduced.

Common issues

QORE blocks arbitrary Python, unsupported imports, filesystem access, network access, and unrestricted shell operations by design. Review terminal diagnostics and rewrite unsupported source into the supported circuit-building subset. If bitstrings seem reversed, read the Lab bit-ordering note: Qiskit classical results use little-endian indices.
