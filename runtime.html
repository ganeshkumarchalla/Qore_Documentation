RUNTIME

Qiskit, Aer, and IBM integrations

QORE’s local execution path uses Qiskit SDK and Qiskit Aer. It includes the IBM Quantum Runtime Python client and selected published research add-ons such as circuit cutting, approximate quantum compilation tensor methods, multi-product formulas, operator backpropagation, and sample-based quantum diagonalization.

Local simulation

Aer is the default local backend. It supports statevector and shot-based workflows used by QORE visualizations and metrics. This route does not need IBM credentials.

Cloud services

IBM Quantum Compute, Functions, and Quantum System services require explicit user authorization and secure backend-only credentials. QORE must never place tokens in the browser, source control, or Vite variables.
