Security and operations

QORE does not expose arbitrary Python execution. It accepts a constrained circuit-building subset and runs it in bounded backend workers.

Public deployments

Use authentication, rate limits, qubit and shot caps, execution timeouts, memory limits, logging, and abuse monitoring. Keep IBM credentials server-side and out of frontend bundles.

Support

Capture source, project path, backend, shots, seed, terminal output, warnings, and metadata. Never include secrets or tokens.
