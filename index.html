Understand the scope

QORE supports a bounded circuit-building subset of Qiskit and OpenQASM 2, with explicit size and operation limits. It does not execute arbitrary Python or imply quantum-hardware access. Active files have no automatic expiry; deleted file content is recoverable for 48 hours.
