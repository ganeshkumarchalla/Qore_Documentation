Start with QORE

Quantum foundations

Learn qubits, superposition, measurement, gates, interference, and entanglement through QORE’s visual State World and Bloch views.

Quantum Lab

Edit a Qiskit circuit, run Qiskit Aer locally, compare ideal and measured distributions, and inspect amplitudes, matrices, OpenQASM, and execution metadata.

Quantum Ledger

Use source hashes, seeds, shots, TVD, timestamps, warnings, and historical snapshots to understand and reproduce every experiment.

Suggested learning path

  1. Understand the qubit and measurement.
  2. Build a two-qubit circuit with H and CX gates.
  3. Run it in QORE with a fixed seed and shots.
  4. Compare the Bloch, State World, and distribution views.
  5. Read the Ledger and export the run evidence.

Source orientation: IBM Quantum Learning presents fundamentals, quantum-computing paths, optimization, data science, physics and chemistry, algorithm development, classroom modules, Composer, and tutorials. QORE turns those concepts into an editable, local-first learning workflow.
