FOUNDATIONS

Qubits & states

A qubit is described by amplitudes α and β with |α|²+|β|²=1. Before measurement it can occupy a superposition; measurement samples a classical outcome according to those probabilities.

Use the Bloch sphere to read a single-qubit state geometrically. Its axes represent basis directions, its vector represents the state, and its purity indicates how mixed the state is. QORE exposes these values interactively so the mathematics stays connected to the circuit.

FOUNDATIONS

Circuits & gates

Quantum circuits are ordered transformations. H creates superposition, X flips a basis state, Z changes phase, and CX applies a conditional operation that can create correlations.

from qiskit import QuantumCircuit
qc = QuantumCircuit(2, 2)
qc.h(0)
qc.cx(0, 1)
qc.measure_all()

Change one gate at a time and compare the distribution, statevector, and Bloch output. That controlled contrast is the fastest way to develop intuition.

FOUNDATIONS

Measurement & probability

A shot is one execution. Repeating a circuit produces a sampled distribution. The ideal statevector describes amplitudes before measurement; counts show what finite sampling actually observed.

QORE reports total variation distance to quantify divergence between measured and ideal distributions. Increase shots to reduce sampling uncertainty, and use a fixed seed when you need a repeatable comparison.

FOUNDATIONS

Entanglement & interference

Entanglement means the joint state cannot be represented as independent single-qubit states. Interference makes probability amplitudes reinforce or cancel, which is why circuit order matters.

Inspect correlated outcomes in State World and compare each qubit’s local Bloch view with the complete register distribution. The distinction between local state and joint state is central to quantum reasoning.

VISUAL EXPLORATION

State World & Bloch views

State World maps basis states into an orbital scene. Node glow represents measured frequency while the state readout shows ideal probability, measured probability, and counts. Drag to orbit and click a node to inspect it.

Bloch view supports focused and all-qubit modes with axes, interactive rotation, animated vectors, purity, polar angle, and phase. Use the focused mode for detail and all-qubit mode for register-level comparison.

EVIDENCE

Quantum Ledger

The Ledger preserves backend, shots, seed, noise model, execution time, timestamp, TVD, source hash, framework versions, warnings, and historical snapshots.

This record helps students explain a result, helps teams review a change, and helps researchers reproduce an experiment. Capture the file path and terminal output when requesting support.

ECOSYSTEM

Qiskit & Aer

Qiskit provides the circuit model and Python APIs. Qiskit Aer provides simulators for statevectors, unitaries, shot sampling, and noise models. QORE presents these capabilities through an editable visual workflow.

Use the official references for current APIs and hardware workflows: Qiskit docs and Qiskit Aer.

OPERATIONS

Deployment & support

QORE suits classrooms, workshops, research prototypes, and internal experimentation. Local simulation is deterministic when a seed is fixed; real hardware adds queueing, calibration drift, noise, and device constraints.

For support, capture the project path, source, terminal output, backend, shots, seed, and execution metadata.
