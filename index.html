ORIENTATION

QORE workflow

QORE follows a simple loop: edit, run, inspect, explain, and preserve.

  1. Create or open a project in Explorer.
  2. Write a Qiskit circuit in the editable workspace.
  3. Run a reproducible local simulation.
  4. Use visual output to understand state and measurement.
  5. Review the Ledger and export evidence.
FOUNDATIONS / 01

Qubits & states

A classical bit is 0 or 1. A qubit is described by amplitudes α and β, where |α|² + |β|² = 1. Measurement converts that description into a classical result.

The Bloch sphere is a geometric view of a single qubit. QORE makes the state, axes, vector, purity, and phase visible.
FOUNDATIONS / 02

Circuits & gates

Quantum gates are reversible transformations. H creates balanced superposition, X flips a state, and CX creates conditional behavior between two qubits.

qc.h(0)
qc.cx(0, 1)
qc.measure_all()
FOUNDATIONS / 03

Measurement & probability

One run produces a bitstring; many shots produce a distribution. QORE compares measured frequencies with ideal statevector probabilities and reports total variation distance.

FOUNDATIONS / 04

Entanglement & interference

Entanglement creates correlations that cannot be represented as independent single-qubit states. Interference amplifies some paths and cancels others, forming the basis of many quantum algorithms.

Run your first experiment

Quantum Lab is the execution surface for QORE. Set shots, seed, optimization level, and noise options, then run the circuit against the local Aer statevector simulator.

  1. Open a Python circuit.
  2. Choose simulation settings.
  3. Run from the toolbar or terminal.

VISUAL EXPLORATION

State World & Bloch views

State World presents basis states as an interactive orbital scene. Bloch views expose individual qubit vectors or an animated all-qubit register view. Drag to orbit and select a state to inspect its ideal, measured, and shot values.

EVIDENCE

Quantum Ledger

The Ledger preserves run context: backend, shots, seed, noise model, execution time, timestamp, TVD, source hash, framework versions, warnings, and historical snapshots.

ECOSYSTEM

Qiskit & Aer

Qiskit is an open-source framework for constructing and executing quantum circuits. Qiskit Aer provides simulators for statevectors, unitary matrices, noise models, and shot-based experiments.

OPERATIONS

Deployment & support

QORE suits classrooms, workshops, research prototypes, and internal experimentation. Local simulation is deterministic when a seed is fixed; real hardware adds queueing, calibration drift, and device-specific noise.

For support, capture the project path, circuit source, terminal output, backend, shots, seed, and run metadata.
REFERENCE

Glossary

Amplitude: complex coefficient. Basis state: computational state such as |00⟩. Shot: one execution. TVD: distance between distributions. Statevector: ideal amplitude representation. Transpilation: rewriting for a target backend.
