VISUAL EXPLORATION

State World and Bloch views

QORE renders several views because no one representation explains every quantum result. Use distributions for observed measurement statistics, State World for register-level basis outcomes, and Bloch spheres for individual qubit state geometry.

State World

Each visible basis state has ideal probability, measured probability, and sampled count. Drag to orbit and select a state to inspect it. The display supports intuition but must be interpreted alongside numeric distributions.

Bloch sphere

A Bloch sphere represents a single qubit’s reduced state. Axes, vector orientation, polar angle, phase, and purity describe the state. In an entangled register, a single Bloch sphere cannot capture the complete joint state.
