Integrated terminal and diagnostics

The QORE terminal exposes execution messages, parse failures, compiler feedback, warnings, and simulation completion output in the same workspace as the circuit source.

Diagnose safely

Read the error code, line context, and allowed-source guidance. QORE rejects arbitrary Python deliberately. Convert unsupported code into the supported circuit-building subset instead of trying to bypass the parser.

Support evidence

When reporting an issue, include the circuit source, active project file path, command used, backend, shots, seed, full diagnostic message, and relevant Ledger entry.
